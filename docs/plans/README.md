# Plans

Longer-lived planning docs — investigations, phased initiatives, refactors that span multiple commits. One file per plan, numbered chronologically.

Distinct from ADRs (in [../decisions/](../decisions/)): ADRs record a *decision* after it's made. Plans record *intent* before/during execution and may be revised or abandoned.
